Sales Performance Dashboard
Overview

This Power BI dashboard provides a consolidated view of sales performance through key business metrics, trend analysis, and product-level insights. The report enables users to monitor performance across different fiscal periods using interactive filters and visualizations.

Dashboard Features
KPI Summary

The dashboard includes key performance indicators for:

Sales
Cost
Profit
Units Sold

Each KPI card displays:

Current period value
Previous month value
Month-over-month variance
Time-Based Analysis

Interactive date filtering allows users to analyze performance by:

Date Range
Fiscal Year
Fiscal Quarter
Trend Analysis

A monthly trend chart helps identify:

Sales patterns over time
Seasonal fluctuations
Growth and decline periods
Product Performance

A product-wise sales analysis visual highlights:

Product contribution to overall sales
Relative product performance
Top-performing products
